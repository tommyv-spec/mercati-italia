# Source check — is the data complete, and can we collect it better?

Started 2026-10-25. One line per source (or group of small sources), biggest first.
"Markets" = markets a visitor sees in the app (copies merged away are not counted).

Status: ⬜ to check · 🔎 checking now · ✅ checked

For every source the same four questions:
1. How do we collect it today, and does that happen automatically?
2. How complete is it (hours, street, upcoming dates, map position)?
3. How fresh is it (when did we last really read the source)?
4. Can we collect it better, and what would that gain?
